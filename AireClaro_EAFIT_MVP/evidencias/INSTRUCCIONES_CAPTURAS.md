# Evidencias para la entrega

Guarda aquí las capturas PNG/JPG de la demostración. En Windows usa **Win + Shift + S** y guarda las imágenes con los nombres de referencia listados en `REGISTRO_PRUEBAS.txt`. Las cinco imágenes adjuntas ya están copiadas en esta carpeta.

Para capturas nuevas, usa la fuente **SIATA · mediciones recientes** en la barra lateral. Deja visibles la estación, el valor, la hora y la fuente. Para probar la clasificación y baseline cambia explícitamente a **Demo · datos simulados** y conserva ese rótulo en la captura.

No marques una pregunta como aprobada solo por tener respuesta correcta: revisa también la etiqueta **Herramientas usadas** cuando el criterio de la prueba exige una herramienta. La captura `02_categoria_sin_herramienta.png` corresponde a la ejecución inicial antes del ajuste; la re-ejecución posterior mostró `get_pm25`, pero falta tomar una captura de esa re-ejecución si se desea reemplazarla como evidencia final.

No captures claves API ni el archivo `.env`. Guarda imágenes adicionales en esta carpeta junto al registro TXT.
